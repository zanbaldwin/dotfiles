Before writing or editing more than a paragraph of prose that will be kept — READMEs, documentation, PR descriptions, commit message bodies, release notes, error or log messages — invoke the ste-writing skill and apply it (STE-flavored mode by default; strict mode for procedures, runbooks, and safety text).

Do not invoke it for: code and identifiers, conversational answers, single-sentence edits, scratch notes, or implementation plans created by the planning agent / in plan mode — plans are working documents, not deliverable prose.
