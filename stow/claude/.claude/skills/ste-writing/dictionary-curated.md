# ASD-STE100 Issue 9 — Dictionary (curated for software/general prose, 996 entries)

Subset of dictionary-full.md: replacement rules and restricted approved words that appear in software
documentation and general technical prose. Aviation/workshop-specific vocabulary is omitted, as are
plain approved-word entries. A word absent from this file may still be approved or restricted —
check dictionary-full.md when in doubt.

Entry format, one line per head word:
- `word (pos) → ALTERNATIVE (pos)` — the word is NOT approved in STE; replace it with the UPPERCASE alternative. `[brackets]` give the sense an alternative applies to, or an instruction when no single replacement exists.
- `WORD (pos) = meaning` — the UPPERCASE word is approved, but only with the stated meaning; `other meanings:` lists what to use instead for different senses.
